# Metropolis web fonts

Metropolis Regular and Bold were downloaded from Michigan State University's
[official typography page](https://brand.msu.edu/visual/typography), which
identifies Metropolis as its primary brand typeface and an openly available font.

[MSU font archive](https://msu-p-001.sitecorecontenthub.cloud/api/public/content/165c9772ef404412821073f2176a326d?v=6f842ddf)

Retrieved 25 September 2026. The supplied Regular and Bold TTF files were
compressed to WOFF2 using fontTools, preserving their glyphs. Files are served
locally with `font-display: swap` and Arial/Helvetica fallbacks so the presentation
does not depend on a third-party font service. Typeface design: Chris Simpson.
