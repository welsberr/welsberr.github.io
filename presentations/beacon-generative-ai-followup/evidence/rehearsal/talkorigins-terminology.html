From a technical term to four translation targets

A glossary gives a model specific terminology to follow; it does not certify the resulting prose.

1 · Define the terminology

Make the choices inspectable

The site-wide compendium records English scientific phrases, site names, and recurring navigation labels alongside targets for Spanish, French, German, and Portuguese. It separates a choice about a technical phrase from the translation of a whole page. A separate earlier research compendium records evidence and review for many related terms; the available records do not establish whether this later runner compendium was generated from it.

Follow the recorded earlier terminology research and source trail.

A repeatable way to build one: identify recurring domain terms and site labels; choose a target for each language; record context or distinctions where a word has more than one meaning; then have a fluent subject specialist review the targets and examples. This describes a reviewable method, not a documented account of how each existing entry was chosen.

For example, genetic drift maps to deriva genética, dérive génétique, genetische Drift, and deriva genética. These are the compendium’s specified targets, not a claim that every use is correct in context.

2 · Use the glossary

Give the translator a target-language view

  1. Load the shared compendium and select the targets for one language. Optional language-specific glossaries overlay shared entries; later entries can replace earlier ones.
  2. Send the selected mappings as instructions alongside the source content. The prompt asks the model to preserve meaning and structure. This is a requested constraint, not an enforcement guarantee.
  3. Inspect the output and its markup; resolve language and subject-matter concerns before treating it as reviewed. Queue state and structural checks alone do not validate meaning.

Avida-ED later adapted the approach for a Spanish UI catalog: its own glossary distinguishes update from generation, masks runtime placeholders, and records provenance. It can also read selected Spanish terms from the TalkOrigins compendium; this is process reuse, not an imported SciSiteForge translator.

3 · Evidence and boundaries

Show a result and its limits

A contemporaneous maintainer note records a successful local Spanish translation probe: “Natural selection changes allele frequencies in populations.” → “La selección natural cambia las frecuencias alélicas en poblaciones.” The note lists that probe before the compendium was added, so it does not demonstrate that the glossary caused the result.

The same note reports a later one-page Spanish smoke test that retained HTML structure and used the mapped terms Archivo TalkOrigins and Índice de afirmaciones creacionistas. The current Spanish front page provides a separate view of a translated artifact; it is not proof that the page is unchanged from that smoke test.

Positive: the recorded probe produced a Spanish sentence and the later smoke test reported retained HTML structure. Open: the records do not establish expert approval of the mappings or translations; grammar, scientific sense, and context still require human review.
