Author and acknowledgements

Author

Project author and research lead: Wesley R. Elsberry. This is an independent, human-directed analysis prepared with substantial generative-AI assistance. The project author set the research questions and scope, directed source comparisons and interpretive emphasis, and is responsible for the analysis and any corrections. AI-generated suggestions and draft language are not independent evidence; findings are grounded in the cited corpus and remain subject to correction as additional records become available.

Acknowledgements and use of generative AI

OpenAI ChatGPT and OpenAI Codex (GPT-6-family model) assisted with research planning, public-source discovery, document and metadata review, search-query design, candidate-source screening, crosswalk and graph construction, analysis drafting, and editing. Codex also used delegated AI research agents for bounded source-search and standards-crosswalk tasks. A ChatGPT analysis supplied by the project author was used as a research roadmap; its claims were treated as leads to check against source documents, not as evidence in themselves. The exact model build, prompts, and complete interaction logs were not retained as part of the public research corpus.

Software and research workflow

  • Python 3 and project scripts were used to inventory and organize source records, build crosswalk tables and the benchmark variant graph, and produce the analysis data.
  • NumPy, SciPy, and scikit-learn power the corpus search: word and two-word TF-IDF plus truncated-SVD latent semantic indexing. The resulting similarity rankings helped locate passages for review; they do not establish source lineage or copying.
  • PyMuPDF extracted PDF text by page; catppt extracted text from legacy PowerPoint files. Poppler pdfinfo and pdfdetach, and pdftk were used to inspect PDF metadata, attachments, and annotations.
  • The cached Jina v4 embeddings model was smoke-tested but was not used to index the corpus. The corpus search used the local TF-IDF/SVD method.
  • Git and GitHub Pages provide version control and public hosting. Public web sources and the Internet Archive helped locate historical standards and records.

Epistemap, GroundRecall, and Didactopus were not part of the original research-production pipeline for this analysis. The benchmark graph was built with the project’s custom Python script and JSON schema; semantic retrieval used the documented TF-IDF/SVD workflow. GroundRecall was queried only during a later audit of whether these tools had been used; that bounded prior-work query returned no project record. During follow-up, the Didactopus repository and graph-analysis documentation were inspected as a possible method, but the analyzer was not run because the current standards graph has no reviewed prerequisite edges for it to assess. No findings in the current comparison were generated by these repositories or services.

These tools supported discovery, extraction, organization, comparison, and publication. Similarity rankings and AI-generated summaries were treated as research aids, not proof of copying, authorship, intent, or unauthorized access. No AI-text detector was used to infer whether FDOE drafted the standards with generative AI. The available 2026 PDFs do not preserve source-document revision history, so this analysis cannot determine whether generative AI was used in preparing the standards under review. See the process and metadata review for the evidence needed to investigate that question, and the search methods note for the corpus index details.
